## Where does OshiYobi's data come from?

OshiYobi brings together public information from different sources, so streams, videos, and channel data can all be viewed in one place.

Different features don't necessarily use the same data source. Below is an explanation of the data sources OshiYobi currently relies on, and where each one is used.

## Livestreams and upcoming streams

The VTuber livestream and upcoming-stream information OshiYobi shows comes from the **Holodex API**.

The Holodex API provides currently-live streams, upcoming streams, and related stream timing information.

OshiYobi uses this data to show:

- Live stream status
- Upcoming streams
- The Schedule stream calendar
- Notification features related to stream timing

This lets you view different creators' stream information in one place, without opening every channel individually.

## YouTube-related data

Video, channel, and view-count data mainly come from public information on YouTube.

OshiYobi organizes this data to show recent videos, channel information, content ordering, and features related to video performance.

When you look at what's currently getting the most attention, OshiYobi also uses actual numbers like view counts as the basis for ordering.

## Historical records OshiYobi keeps

Some public numbers are recorded periodically by OshiYobi.

For example, the view count of the same video on different dates can show how much it has grown since then; a channel's public numbers can likewise be compared across different recorded dates.

Because of this, some of the growth information OshiYobi shows isn't provided directly by another platform -- it's compiled from public numbers recorded at different points in time.

## Data update timing

YouTube, Holodex, and OshiYobi each have their own data update timing.

Because of this, OshiYobi may not show the latest content at exactly the same moment a stream starts, a new video is published, or a number updates on the original platform.

Once the next data retrieval completes, the related content is updated accordingly.

## Topics and content classification

Based on the public information it retrieves, OshiYobi organizes some videos and streams into different topics, to make recent content easier to browse.

These topics and classifications are display groupings OshiYobi creates to organize content, and don't necessarily match the official classifications used by YouTube or Holodex themselves.

**Data comes from different places -- OshiYobi's job is to organize it into something easier to find and easier to understand.**
