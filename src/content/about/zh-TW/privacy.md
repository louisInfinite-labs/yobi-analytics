## OshiYobi 如何處理你的資料？

OshiYobi 不需要登入帳戶。

大部分個人化設定都只會保存在你目前使用的瀏覽器內。只有推送通知等需要後台運作的功能，才會把完成該功能所需要的資料傳送到 OshiYobi 的後台。

## 你的設定會保存在哪裡？

你關注或收藏的創作者、顯示與篩選等一般設定，都會保存在目前瀏覽器的 **Local Storage（本機儲存空間）**。

這些設定不會綁定你的 Google 或 YouTube 帳戶，也不會交給 YouTube 或 Holodex。

如果你更換瀏覽器、裝置，或清除網站資料，相關設定可能需要重新設定。

## 推送通知

推送通知需要知道通知應該送到哪一個瀏覽器，因此會使用一個 **Browser Client ID**。

你可以把它理解成瀏覽器的隨機編號。它不包含你的姓名、電郵、Google 或 YouTube 帳戶資料。

啟用推送通知後，Browser Client ID、通知設定，以及發送通知所需要的技術資料，會傳送到 OshiYobi 運行於 **Amazon Web Services（AWS）** 的後台。

這些資料只用來保存你的通知設定，以及把通知送到正確的瀏覽器。

## 網站運作紀錄

使用 OshiYobi 時，系統可能會產生維持網站正常運作所需要的技術紀錄。

這些紀錄主要用於找出錯誤、維持服務穩定，以及防止不正常的使用。

它們不會用來建立你的興趣檔案，或決定你應該看到哪些 VTuber 內容。

## YouTube API Services

OshiYobi 使用 **YouTube API Services** 取得部分公開的影片與頻道資料。

Google 對相關服務的資料處理方式，請參閱：

[Google Privacy Policy](https://policies.google.com/privacy)

## 第三方資料來源

OshiYobi 的部分功能會使用第三方提供的公開資料。

直播與直播預告資料來自 **Holodex API**；影片、頻道、觀看次數與頻道頭像等資料則以 YouTube 提供的公開資訊為基礎。

你的 OshiYobi 本機設定不會因為使用這些資料來源而提供給 YouTube、Google 或 Holodex。

## 你的選擇

你可以隨時修改 OshiYobi 的設定，或在瀏覽器中關閉推送通知。

你亦可以透過清除瀏覽器的網站資料，移除保存在 Local Storage 的設定。
