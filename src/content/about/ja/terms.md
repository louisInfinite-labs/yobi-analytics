## OshiYobi の利用

OshiYobi は、VTuber の配信・動画・公開データを整理する情報サービスです。

OshiYobi を利用することで、配信状況、配信予定、最近のコンテンツ、通知、その他サイトが提供する機能を確認できます。

本サイトを利用することで、本ページに記載された利用規約に従うことに同意したものとみなされます。

## データソース

OshiYobi の一部のコンテンツは、第三者のサービスから提供されています。

配信・配信予定データは **Holodex API** が提供する情報を使用しています。

動画・チャンネル・再生回数などのデータは、YouTube が提供する公開情報に基づいています。

OshiYobi はこれらのデータをサイトの機能のために整理していますが、関連するコンテンツ、名称、商標、その他の権利は、それぞれ元の権利者に帰属します。

明示的な説明がない限り、OshiYobi と YouTube、Google、Holodex、および本サイトに登場する VTuber、事務所、その他の関連企業との間に、公式な提携、代理、または従属関係はありません。

## 推しのチャンネルアイコン

OshiYobi が表示する推しのアイコンは、**YouTube Data API** が提供するチャンネルサムネイル（Channel Thumbnail）を使用しています。

これらの画像は YouTube API から提供される画像データのとおりに表示され、画像内容の加工や再作成は行っていません。

チャンネルアイコンおよび関連コンテンツの権利は、元のチャンネルまたは対応する権利者に帰属します。

## YouTube

OshiYobi は **YouTube API Services** が提供する一部の公開データを使用しています。

OshiYobi を利用する際は、YouTube の利用規約にも同意したものとみなされます。

[YouTube Terms of Service](https://www.youtube.com/t/terms)

## データに遅延が生じる場合があります

OshiYobi は正確かつ最新の情報を提供するよう努めていますが、各データソースにはそれぞれ独自の更新タイミングがあります。

そのため、配信状況、配信時間、再生回数、その他のデータが、元のプラットフォーム上で現在表示されている内容と一時的に異なる場合があります。

最新の情報を確認する必要がある場合は、元のプラットフォーム上の内容を優先してください。

## サイトの利用について

OshiYobi を以下の目的で使用しないでください：

- サイトの正常な運用を妨げる行為
- 大量または異常な自動化されたリクエスト
- 公開されていないシステムやデータへのアクセスの試み
- サービスまたは他の利用者に影響を与えるおそれのあるその他の行為
